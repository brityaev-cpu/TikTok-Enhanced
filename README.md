# TikTok Enhanced v0.3 (неофициальный клиент)

## Возможности
- Настоящий сайт TikTok во встроенном окне, сохранение входа из v0.2 (partition persist:tiktok).
- Автопереключение **после фактического завершения видео** (если сайт не зацикливает его сам).
- Режим фокуса (экспериментальный CSS), мини-окно, поверх всех окон.
- Пауза, звук, громкость, скорость, навигация.
- «↓ MP4»: пытается сохранить **прямой HTTPS-адрес уже воспроизводимого видео**, если он доступен. При `blob:` или недоступном URL копирует ссылку страницы. Не обходит DRM, приватность или ограничения TikTok. Соблюдайте права авторов и правила сервиса.
- Сборка Windows: установщик NSIS и portable.

## Запуск
1. Распакуйте проект в `C:\Projects\tiktok-enhanced-v0.3` (не поверх старой версии).
2. В PowerShell в папке проекта: `npm install --foreground-scripts` и `npm start`.
3. Если Electron опять не распакуется, проверьте `Test-Path .\node_modules\electron\dist\electron.exe`. Не отключайте антивирус. Сохраните старую рабочую v0.2.

## Сборка установщика
`npm run dist` (NSIS) или `npm run dist:portable` (portable). Файлы появятся в `dist`. Для сборки нужен интернет, Windows и установленный Electron. **Готовый EXE не включён в ZIP.**

## Ограничения
TikTok меняет сайт, поэтому элементы управления могут перестать работать. Автопереключение не срабатывает на бесконечно зацикленных видео. Управление громкостью/скоростью применяется к текущему HTML-video и может сбрасываться при смене ролика. Прямое скачивание зависит от доступности адреса видео и может не работать из-за правил сайта/сети. Сторонние ссылки открываются в браузере.

## Безопасность
Контент TikTok работает без Node.js интеграции, IPC принимает команды только из локальной панели. Не запускайте `npm audit fix --force` без проверки совместимости. Это неофициальное приложение и не связано с TikTok.
